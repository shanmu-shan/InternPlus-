InternPulse – Internship Task Management System

InternPulse is a web-based application designed to simplify internship management. It allows HR administrators to assign tasks to interns, set submission deadlines and review dates, and track task progress.

Interns can view assigned tasks, submit completed work, and receive feedback. The application also includes a multilingual chatbot supporting Tamil, English, and Hindi to help users interact easily.

Key Features

- HR dashboard for intern and task management
- Task assignment with deadlines and review dates
- Intern dashboard to track and submit tasks
- Task status and review feedback
- Multilingual chatbot with voice interaction
- Simple, responsive user interface

Objective

To make internship task assignment, submission, and review easier through a single platform.
